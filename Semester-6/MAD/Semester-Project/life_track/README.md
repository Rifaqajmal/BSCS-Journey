# LifeTrack (Semester Project — Original Version)

A Flutter "Age & Birthday Tracker" app built for my Mobile Application
Development (MAD) semester project — BS Computer Science, 6th semester,
UET Mardan.

Tracks birthdays with real-time sync, a live age calculator, and local
reminder notifications, backed by Firebase.

## Features

- Firebase Authentication (email/password)
- Add, edit, and delete birthdays, synced in real time via Firebase
  Realtime Database
- Live age calculator (years, months, days, hours)
- Zodiac sign calculation from date of birth
- Local birthday reminder notifications
- Search and sort across saved birthdays

## Tech Stack

- Flutter / Dart
- Firebase Authentication
- Firebase Realtime Database
- Provider (state management)
- flutter_local_notifications
